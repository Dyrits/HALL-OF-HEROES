# Hall of Heroes

An Express/Mongoose web application built while following the Udemy course "The Complete Web Developer Master Course".

## About The Project

This project is a Node.js/Express app with MongoDB (Mongoose) and EJS views, organized in an MVC structure. It was originally deployed on Heroku.

## Built With

- Node.js / Express
- MongoDB / Mongoose
- EJS

## Getting Started

### Prerequisites

- Node.js and npm
- A MongoDB connection

### Installation

```bash
npm install
```

### Running the app

```bash
npm start
```
